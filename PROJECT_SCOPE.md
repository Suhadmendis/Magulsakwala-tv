# Project Scope

## Overview

Magulsakwala-tv is a social media automation web application. It provides tools to automate and manage social media activity through a React frontend and a PHP backend.

## Goals

- Automate recurring social media tasks (e.g., scheduling, posting, content management).
- Provide a web-based interface for managing automation workflows.

## Tech Stack

- Frontend: React
- Backend: PHP

## Out of Scope

- Python is not used anywhere in this project (no scripts, tooling, or services).
- Node.js is not used anywhere in this project (no npm-based build tooling or Node services).

## Status

This is a living document. Scope, features, and priorities will be updated as the project evolves.
